## 实际服务请求

以Java 17运行 `target/lovelab-backend-0.1.0.jar`，local环境8080端口、H2文件数据库。Flyway初始化和内容种子导入完成，健康检查返回UP。

执行 `backend/scripts/smoke.ps1`，通过真实HTTP和Cookie完成：

1. 注册独立测试账号，登录后重取CSRF。
2. 开始倾听剧场，重复提交第一幕仍只有一个选择记录。
3. 完成第二幕，服务器返回COMPLETE。
4. 收藏和标记一篇已读，提交今日题。
5. 汇总返回完成1局、已读1篇、收藏1项、练习1天，最后登出。

该脚本会在本地数据库创建独立USER测试账号与示例记录，不保存或打印测试密码。集成测试使用另一份内存数据库，不修改本地文件。
